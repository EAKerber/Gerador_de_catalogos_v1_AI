# Estudo de caso — catálogo técnico A4

Classificação: **referência forte e critério canônico da V1**. A imagem é
evidência externa; não é golden image nem autorização para comparação pixel a
pixel.

| Região | Classificação | Tradução no kit |
| --- | --- | --- |
| cabeçalho e título | direta | `catalog-header`, textos, arte/logo e separadores |
| hero técnico | composição | `product-card` hero/technical, arte, specifications e tabela |
| grade de produtos | direta | receita `section-hero-grid-strip`, cards e tabelas semânticas |
| cores/modelos | direta | variantes, galeria, linhas ligadas e legendas |
| aplicações | direta | receita `section-applications` e ícones publicados |
| legenda de embalagens | direta | `legend-panel`/`legend-item` |
| dica e rodapé | composição | callout, `catalog-footer`, `footer-item` e `slot.span` |

Como esta referência agora está decomposta no material didático, o ensaio cego
final deve usar uma terceira referência inédita.
