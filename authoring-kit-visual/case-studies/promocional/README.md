# Estudo de caso — peça promocional Pé para Móveis

Classificação: **benchmark pós-V1 não bloqueante**. Ele mede compatibilidade de
categoria visual, não reprodução pixel a pixel.

| Região | Classificação | Tradução no kit |
| --- | --- | --- |
| quatro ofertas/preços | direta | `commerce-offer-unit` e `commerce-price-block` |
| benefícios técnicos | direta | `fact`, specification, ícones e textos |
| período e callout | composição | textos, separadores e `section-tip-callout` |
| desenho técnico | composição | arte factual fornecida; não gerar medidas |
| título publicitário extremo | aproximação | tipografia declarativa com perda controlada |
| personagem recortado e sobreposições | fora da V1 | exigem composição livre/camadas pós-V1 |
| selo explosivo | aproximação/pós-V1 | callout simples, sem prometer a forma irregular |

A ausência de personagem ou fotografia final não invalida a V1. Não reabra
camadas livres, recortes ou multimídia apenas para perseguir esta referência.
