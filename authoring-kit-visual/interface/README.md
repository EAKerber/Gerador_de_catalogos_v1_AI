# Mapa da interface

`editor-reference.png` é uma captura real produzida no 05.17 em viewport
1366×768. No 05.55, os nomes e contratos das cinco superfícies foram
reverificados: toolbar, painel esquerdo, canvas/contexto, inspetor e status. O
Chromium local não estava disponível para substituir os bytes da captura; a
proveniência permanece explícita em `visual-index.json`.

Ela é material de orientação, não baseline pixel a pixel. Se um controle mudar
de posição, procure primeiro pelo rótulo e depois pelo caminho JSON indicado no
tutorial correspondente.
