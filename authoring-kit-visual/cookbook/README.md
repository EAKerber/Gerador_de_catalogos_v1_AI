# Cookbook visual

Comparações curtas para decidir antes de editar:

- `product-arrangements.svg`: modo editorial versus geometria;
- `semantic-pieces.svg`: `specification`, `fact` ou `legend-item`;
- `table-columns.svg`: identidade e apresentação de colunas;
- `footer-span.svg`: ocupação do slot e escala interna;
- `factual-image-fit.svg`: deformação, recorte e `contain` factual.

O contrato escrito em cada cartão deve existir no manifesto do núcleo. O
cookbook não autoriza CSS arbitrário ou propriedades fora do schema.
