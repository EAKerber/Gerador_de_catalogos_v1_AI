# Revisão do guia visual de autoria — 05.55

## Resultado esperado

O complemento visual deve responder cinco perguntas sem introduzir outra fonte
de verdade:

1. onde a ação está na interface;
2. quando usar a capacidade;
3. qual caminho JSON materializa a decisão;
4. como reconhecer o resultado;
5. qual gate confirma a entrega.

## Cobertura pedagógica

| Área | Evidência |
| --- | --- |
| orientação inicial | `START-HERE.md` e mapa anotado |
| fluxo ponta a ponta | tutorial 01 + documento/relatório executáveis |
| assets factuais | tutorial 02 + comparação stretch/cover/contain |
| linguagem editorial | tutorial 03 + combinações de modo/arranjo |
| tabelas | tutorial 04 + `key`/`label`/ordem/`visible` |
| variantes/legendas | tutorial 05 + vínculos semânticos explícitos |
| rodapé | tutorial 06 + `slot.span` e escala 80% |
| entrega | tutorial 07 + troubleshooting por código |
| catálogo técnico | decomposição direta/composição |
| promocional | direta/aproximação/fora da V1 |

## Limites deliberados

- nenhuma imagem é baseline pixel a pixel;
- o complemento não é necessário para compilar;
- binários não entram em `app/authoring-kit-files.js`;
- pacotes individuais não duplicam o guia;
- a peça promocional não reabre camadas livres, personagem recortado,
  multimídia ou tipografia arbitrária;
- a referência técnica deixa de ser apta a um ensaio cego.
